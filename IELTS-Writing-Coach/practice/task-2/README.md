# Task 2 Practice Workspace

This directory stores candidate Task 2 essay submissions, 3-minute brainstorm blueprints, draft attempts, diagnostic error logs, and revised Band 8 drafts.

### Standard Essay Submission Format:
1. `PROMPT.md`: The authentic examination prompt.
2. `DRAFT.md`: Candidate's raw, unassisted response with word count and time taken.
3. `EVALUATION.md`: Strict 4-criteria examiner diagnostic evaluation, error analysis table, argument depth review, and student-idea-preserving Band 8 rewrite.
