## Error Category Log

### 1. Grammatical Range & Accuracy (GRA)
- `people remains` -> *people remain* (Subject-Verb Agreement error).
- `benefits which includes` -> *benefits which include* (Subject-Verb Agreement error).
- `. because it can expose...` -> Dependent clause severed from independent clause.
- `...with people these new connections...` -> Run-on sentence lacking punctuation/connector.
- `...although academic knowledge is crucial..., however preparing...` -> Double conjunction error (*although* + *however*).
- `crucial for student` -> Countable singular without article (*crucial for students*).
- `While some people believe [...] others argue...` -> Missing comma separating subordinate and main clauses.

### 2. Lexical Resource (LR)
- `diffrent` -> *different*
- `banefits` -> *benefits*
- `acadamic` -> *academic*
- `in working lives` -> *throughout their professional careers*
- `found them in cohort` -> *find themselves stagnating / confined to a routine*
- `new methods of doing things` -> *novel operational methodologies*
- `result better` -> *result in better* (Missing preposition in phrasal collocation)

### 3. Coherence and Cohesion (CC)
- Conversational spoken opener: *"Well I firmly believe..."* -> Academic opening needed.
- Truncation mid-sentence without paragraph closure or conclusion.

### 4. Task Response (TR)
- Total length: 85 words (Shortfall of 165 words).
- Only one side discussed in any depth; View A (remaining in same job) not substantiated; zero concluding summary.
